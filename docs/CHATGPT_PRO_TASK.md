# 敦煌莫高窟第 96 窟建造全过程——交互式 3D 网页重制任务

## 角色与背景

你是外部高级图形工程师。用户提供了一段 116.373 秒、1080×1920、30fps 的参考视频 `ACtgr.mp4`，要求通过编程做成网页，而不是播放或嵌入视频。网页需要尽量完整还原视频中莫高窟第 96 窟大佛及洞窟的建造过程，并允许用户按步骤触发动画。

Codex 是总负责人。你提供的结论和代码会被独立审查、应用和测试，不会被直接视为正确。

## 用户最新否决意见（最高优先级）

当前基线在用户眼里“就是一张图片，垃圾的很”。这意味着现有版本即使内部有 Three.js、时间轴和状态机，也没有产生足够明确、连续、惊艳的视觉运动。禁止只做配色、按钮、字幕、轻微相机移动或其他表面润色。

## 目标

交付一个无需后端、可本地打开的竖屏沉浸式实时 3D 网页。每个步骤点击后都必须出现肉眼清晰的施工动作、材质变化和镜头叙事；同时支持完整自动播放、暂停、拖动、速度和自由视角。

最终体验应接近高质量博物馆互动展项或游戏过场，而不是 PPT、静态海报、视频播放器或简单模型展示。

## 参考视频的核心叙事（需以原视频为准）

1. 完整彩绘大佛与九层楼揭幕，九层楼被拆解以显露佛像。
2. 大佛面部、全身和 35.5m 尺度展示。
3. 回到未开凿崖壁，搭建栈道。
4. 在高处凿出窟门，向内开凿。
5. 先向上凿拱形天花板，利用拱形结构避免坍塌。
6. 从上到下开凿洞窟，并预留大佛石胎。
7. 下方开两个运土洞，碎石和土方从下方运出。
8. 展示约 35.5m 高佛窟与 27.1m 左右石胎。
9. 石胎凿孔并插入木桩。
10. 敷普通粗泥并出现开裂。
11. 使用河床沉淀细土和麦秆提高抗裂性。
12. 多层泥塑由粗到细逐层塑形，加入棉花等植物纤维。
13. 最外层加入蛋清和米汁，塑刀按压收光。
14. 佛像素胎表面变得光洁，随后上色、螺发和面部细节出现。
15. 洞窟墙面依次敷软土、白粉、矿物颜料和壁画。
16. 九层楼重新组装，回到完整莫高窟外观。

## 当前代码与边界

- `mogao/` 是现有无构建依赖的 Three.js 实时 3D 基线。
- `src/70-timeline.js` 已有 116.4 秒镜头、字幕和 16 个章节。
- `build.js` 会把 Three.js 与 `src/*.js` 内联成单个 HTML。
- 允许大幅重构 `mogao/`，但交付仍需保持可离线打开；不能依赖远程 CDN、远程模型或运行时网络。
- 不得嵌入原视频或用预渲染视频冒充实时网页动画。
- 不得把现有代码中“数值变化但画面不可感知”的状态机当成交付完成。
- 保留或改进：自动播放、暂停、进度拖动、速度、章节跳转、自由视角、响应式竖屏画布。
- 不修改工作区其他项目。

## 需要研究和修改的范围

1. 审查现有几何、材质、动画状态机、镜头和交互，指出造成“静态图片感”的根因。
2. 设计并实现可感知的施工动画语言：
   - 实际几何生长/消失/剖切；
   - 大体量碎石、粉尘、落石和工具动作；
   - 栈道梁柱按构件搭建；
   - 开凿面连续推进，洞口与拱顶的体积变化清晰；
   - 石胎从岩芯中逐步显露，而不是突然切换；
   - 木桩逐根敲入；
   - 泥层沿表面传播并体现粗糙、开裂、纤维、细泥和抛光差异；
   - 彩绘沿表面生长，不能只是整体淡入；
   - 壁面泥层、白粉和壁画有分区/刷涂式传播；
   - 九层楼构件有有序拆装。
3. 提升大佛比例、轮廓、面部、手、衣褶、头光、洞窟空间、崖壁纹理、景深、光照、阴影、雾和色彩。
4. 强化步骤 UI：点击后的当前阶段、进度和完成状态必须明确，但 UI 不能遮挡主体。
5. 保证静止在任一关键时间点时也具备高质量构图；运动时变化必须足够大。
6. 优化性能，避免在普通桌面浏览器中卡死。
