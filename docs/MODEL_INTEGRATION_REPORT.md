## 已知视觉边界

导入资产本身是站立佛像，而参考视频中的洞窟主尊更宽、更接近倚坐巨佛。因此本次解决的是“真正使用用户指定的彩绘三维模型”，不是对历史造像姿态和比例的完全还原。若要继续提高参考片一致性，需要换成姿态、衣褶、手印和身宽都匹配的坐佛 GLB，或在建模软件中重塑当前资产。

自动化使用 x64 Node 经 Rosetta 驱动 SwiftShader 软件渲染，本轮冷启动记录为桌面约 52.9 秒、390×844 约 25.6 秒、604×816 DPR2 约 16.6 秒；该数据明显受到测试环境降级警告影响，不能当作真实设备性能结论。模型本身有 342,684 个三角形，弱移动设备仍存在加载与帧率风险。
